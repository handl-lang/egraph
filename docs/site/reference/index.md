# Reference

## Public API

| item | what it is |
|---|---|
| `EGraph` | add terms (`AddTermError`), saturate to a `Stop`, extract |
| `Rewrite` | a rewrite rule with its matcher and cost model |
| `Stop` / `StopReason` | saturation limit and why it ended |
| `Term` / `TermAttr` | the term representation with attribute plumbing |
| `from_kernel` / `to_kernel` | convert to and from the kernel's `Term`/`Value` |
| `dag_cost` | the extraction cost model |
| `Application` / `Derived` | provenance: which rule application derived a term |

## Crate

| crate | role |
|---|---|
| `handl-egraph` | e-graph substrate |

## Build and test

```bash
cargo build     # sibling [patch] tables resolve deps from ../<repo>
cargo test      # cargo test
```

Dependencies are git deps on `branch = "main"`; locally the `[patch]` tables
point at sibling checkouts (regenerated by `scripts/dev-link.sh`).
